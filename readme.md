# StockFlow - Application de Gestion de Stock

Application desktop locale pour gérer un dépôt de boissons.
Stack : React 18 + Vite + TailwindCSS + Tauri 2 + SQLite

## 🚀 DÉMARRAGE RAPIDE
Lire dans l'ordre : docs/etapes/00-PREPARATION.md

## 📁 STRUCTURE
- claude-design-export/ → Maquettes exportées de Claude Design
- database/            → Schéma et données SQLite
- docs/etapes/         → Guide étape par étape pour Claude Code
- templates/           → Fichiers de configuration Tauri/Rust
- src/                 → Code React (créé par Tauri)
- src-tauri/           → Code Rust/Tauri (créé par Tauri)
